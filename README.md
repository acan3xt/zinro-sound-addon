# zinro.net Sound Add-on

zinro.net のゲーム画面向けブラウザ拡張機能です。

## インストール

### Firefox

[Firefox Add-ons からインストール](https://addons.mozilla.org/ja/firefox/addon/zinro-net-sound-add-on/)

### Chrome / Edge

現在はパッケージ化されていない拡張機能として利用できます。手動での読み込み手順は下記の「開発・手動インストール」を参照してください。

## 機能

- 昼・投票・夜タイマーの指定秒数で音通知
- 昼・投票・夜の通知秒数を個別設定
- 新着プレイヤー発言のキーワード部分一致通知
- キーワードを複数登録（改行・カンマ・読点区切り）
- 自分の発言を除外（名前は自動検出、手動指定も可）
- スレ保守用時間通知
  - 現実時刻の分が `:09 / :19 / :29 / :39 / :49 / :59` のときに通知
  - 1分間に `1 / 2 / 3 / 4 / 6` 回から選択し、等間隔で通知
  - 同じ通知タイミングはページをリロードしても重複通知しない
- タイマー・キーワード・スレ保守用時間通知の音量を個別設定
- 各通知音のテスト再生

## 初期設定

- 昼: 空欄
- 投票: `50,30,10,9,8`
- 夜: 空欄
- タイマー通知: ON
- キーワード通知: OFF
- 自分の発言を除外: ON
- スレ保守用時間通知: OFF
- スレ保守用時間通知回数: 1回
- 各通知音量: 70%

## 開発・手動インストール

### Firefox で一時的に読み込む

1. アドレスバーに `about:debugging#/runtime/this-firefox` を入力
2. 「一時的なアドオンを読み込む」を選ぶ
3. このフォルダの `manifest.json` を選ぶ
4. zinro.net のゲーム画面を開く、または再読み込みする
5. ツールバーの拡張機能アイコンから設定する

※ 一時的なアドオンは Firefox 再起動で解除されます。

### Chrome / Edge で読み込む

1. 拡張機能管理画面を開く
2. 「デベロッパーモード」を有効化
3. 「パッケージ化されていない拡張機能を読み込む」
4. このフォルダを選ぶ
5. zinro.net のゲーム画面を再読み込みする

## 実装対象DOM

- タイマー: `#limit_sec`
- ライブ新着発言: `#message` 直下へ追加される `div > span + span`
- 過去ログ: `#message_text`（初期通知対象外）
